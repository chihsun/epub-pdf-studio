# Uiverse UI element notice

The option switches use an adaptation of the iOS-style toggle interaction shown
in the Uiverse article below. The adaptation keeps the repository's existing
checkbox markup, theme colors, focus indicator, and reduced-motion behavior.

- Source: [Uiverse, "10 UI Elements You Can Copy-Paste in 30 Seconds"](https://uiverse.io/blog/10-ui-elements-you-can-copy-paste-in-30-seconds/)
