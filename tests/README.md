# 測試資料

本目錄只保留 `sample.epub`，供人工快速檢查 EPUB 匯入與基本轉檔流程。它是小型手工樣本，包含兩個 XHTML 章節、一張封面 JPEG 與一張 PNG 內文圖片；沒有導覽目錄或 NCX，可用來檢查從章節標題建立書籤的備援流程。它不是自動化測試套件。

## 使用方式

在網站選取 `sample.epub`，確認章節順序、封面與內文圖片、PDF 文字可搜尋，以及章節書籤是否出現。其他功能可依 README 的「測試資料與手動檢查」清單，以適當的本機文件驗證。

## 維護原則

- 只加入能重現功能或回歸問題的小型測試素材，並確認素材可合法散布。
- 大型 EPUB／PDF、個人書籍、轉換輸出、截圖、日誌與暫存檔留在 repository 外。
- 若測試素材不再對應現有功能，先確認沒有文件或人工驗證流程依賴它，再移除或替換。
